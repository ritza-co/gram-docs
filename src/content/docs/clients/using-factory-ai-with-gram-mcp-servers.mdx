The Factory CLI [`droid`](https://docs.factory.ai/cli) is an AI-powered development tool for automating coding tasks and workflows directly from your terminal. It provides an interactive AI assistant that can work with your codebase and tools.

When combined with [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) servers, `droid` becomes even more powerful. Using MCP servers, you can give `droid` agents access to your tools and infrastructure, allowing them to work with your APIs, databases, and other services.

This guide demonstrates how to connect `droid` to a [Gram-hosted MCP server](/gram-quickstart) using Taskmaster, a full-stack CRUD application for task and project management. Taskmaster includes a web UI for managing projects and tasks, a built-in HTTP API, OAuth 2.0 authentication, and a Neon PostgreSQL database for storing data. Try the [demo app](https://taskmaster-speakeasyapi.vercel.app/) to see it in action.

You'll learn how to set up the connection, test it, and use natural language to manage tasks, projects, and workflows via `droid`.

Find the full code and OpenAPI document in the [Taskmaster repository](https://github.com/speakeasy-api/taskmaster).

## Prerequisites

To follow this tutorial, you need:

- A [Gram account](https://app.getgram.ai)
- The Factory CLI [`droid`](https://docs.factory.ai/cli) installed on your machine
- A project directory to work in

## Setup

First, verify that `droid` has been installed correctly:

```bash
droid --version
```

If installation was successful, you'll see the `droid` version number.

## Creating an MCP server

Before connecting `droid` to a Taskmaster MCP server, you first need to create one. Follow our guide to [creating a Taskmaster MCP server](/examples/creating-taskmaster-mcp-server).

## Connecting droid to your Gram-hosted MCP server

The Factory CLI supports two types of MCP server connections:

- **stdio** for local processes
- **HTTP** for remote endpoints

Gram-hosted MCP servers like the Taskmaster server use the HTTP method for direct connections.

To add an MCP server, you first need to start a `droid` session in your project directory:

```bash
droid
```

Then you need to use the `/mcp add` command. How you configure this command depends on the type of authentication your Taskmaster MCP server uses.

### Pass-through authentication

If you're using the **Pass-through Authentication** configuration, run the following command (replace `<your-api-key>` with your Taskmaster API key and `your-taskmaster-slug` with your MCP server slug):

```
/mcp add --type http taskmaster https://app.getgram.ai/mcp/your-taskmaster-slug -H "MCP-TASKMASTER-API-KEY: <your-api-key>"
```

This command:

- Creates an MCP server configuration named `taskmaster`
- Uses HTTP transport to connect directly to the Gram-hosted MCP server
- Passes the Taskmaster API key as a header

### Managed authentication

If you're using the **Managed Authentication** configuration, run the following command (replace `<your-gram-api-key>` with your actual Gram API key and `your-taskmaster-slug` with your MCP server slug):

```
/mcp add --type http taskmaster https://app.getgram.ai/mcp/your-taskmaster-slug -H "Gram-Environment: default" -H "Authorization: Bearer <your-gram-api-key>"
```

This command:

- Creates an MCP server configuration named `taskmaster`
- Uses HTTP transport to connect directly to the Gram-hosted MCP server
- Uses the default Gram environment (change `default` to your environment name if needed)
- Passes the Gram API key in the Authorization header

## Verifying the connection

Check that you've added the server successfully by running:

```
/mcp list
```

You should see `taskmaster` in the list of configured servers.

To see the full configuration details, run the following command:

```
/mcp get taskmaster
```

This displays the server type, URL, headers, and other configuration details.

## Testing the setup

## Managing MCP servers

The Factory CLI provides several `/mcp` slash commands for managing your MCP server configurations from within a `droid` session:

- `/mcp list` shows all configured MCP servers with their basic information.
- `/mcp get taskmaster` displays the full configuration for a specific server.
- `/mcp remove taskmaster` removes the Taskmaster MCP server configuration from `droid`.

## Troubleshooting

Let's go through some common issues and how to fix them.

### Server not found

If `droid` can't find your server:

- Check whether the server is listed.

  ```
  /mcp list
  ```

- Then remove and re-add the server.

  ```
  /mcp remove taskmaster
  /mcp add --type http taskmaster https://app.getgram.ai/mcp/your-taskmaster-slug -H "MCP-TASKMASTER-API-KEY: <your-api-key>"
  ```

### Authentication errors

If you encounter authentication errors:

- Verify your Gram API key in the Gram dashboard under **Settings → API Keys**.
- For managed authentication, check that the `Authorization` header is correctly formatted in the `/mcp add` command.
- For pass-through authentication, ensure your Taskmaster API key is correct.
- Verify that the Taskmaster API base URL is accessible.

### Configuration format issues

If you have issues with environment variables or headers:

- For HTTP servers, use the `-H "Key: Value"` format (note the colon and space).
- For stdio servers, use the `-e KEY=VALUE` format.
- Ensure the headers and environment variables are properly formatted without extra quotes.

### Tool calls not working

If `droid` isn't calling the tools:

- First, test the MCP server in the **Gram Playground** to ensure it's working correctly.
- Check that the toolset includes the tools you want to use.
- Verify that the environment has been correctly configured with the required variables in Gram.
- Use `/mcp get taskmaster` to confirm that the server configuration is correct in `droid`.

### Tools not appearing

If the tools aren't available:

- First, test the MCP server in the **Gram Playground** to ensure it's working.
- Check that the toolset includes the tools you want to use.
- Verify that the environment has been correctly configured in Gram.
- Run `/mcp list` to confirm that you've loaded the server in `droid`.
