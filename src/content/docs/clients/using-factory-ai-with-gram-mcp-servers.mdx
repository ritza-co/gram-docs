[Factory CLI (droid)](https://docs.factory.ai/cli) is an AI-powered development tool that helps automate coding tasks and workflows directly from your terminal. It provides an interactive AI assistant that can work with your codebase and tools.

When combined with [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) servers, Factory CLI becomes even more powerful. Using MCP servers, you can give Factory CLI agents access to your tools and infrastructure, allowing them to work with your APIs, databases, and other services.

This guide shows you how to connect Factory CLI to a [Gram-hosted MCP server](/blog/the-easiest-way-to-host-mcp-servers) using Taskmaster, a full-stack CRUD application for task and project management. Taskmaster includes a web UI for managing projects and tasks, a built-in HTTP API, OAuth 2.0 authentication, and a Neon PostgreSQL database for storing data. Try the [demo app](https://taskmaster-speakeasyapi.vercel.app/) to see it in action.

You'll learn how to set up the connection, test it, and use natural language to manage tasks, projects, and workflows through Factory CLI.

Find the full code and OpenAPI document in the [Taskmaster repository](https://github.com/speakeasy-api/taskmaster).

## Creating an MCP server

Before connecting Factory CLI to a Taskmaster MCP server, you first need to create one. Follow our guide to [creating a Taskmaster MCP server](/build-mcp/creating-taskmaster-mcp-server).

## Prerequisites

- A [Gram account](https://app.getgram.ai)
- [Factory CLI (droid)](https://docs.factory.ai/cli) installed
- A project directory to work in

## Setup

First, verify that Factory CLI is installed correctly:

```bash
droid --version
```

If installation is successful, you'll see the Factory CLI version number.

## Connecting to your Gram-hosted MCP server

Factory CLI supports two types of MCP server connections: **stdio** (for local processes) and **HTTP** (for remote endpoints). Gram-hosted MCP servers use the HTTP method for direct connections.

To add an MCP server in Factory CLI, start a `droid` session and use the `/mcp add` command.

### Pass-through Authentication

If you're using the **Pass-through Authentication** configuration:

1. Start Factory CLI in your project directory:
```bash
droid
```

2. Add the MCP server using the `/mcp add` command (replace `<your-api-key>` with your Taskmaster API key and `your-taskmaster-slug` with your MCP server slug):

```
/mcp add --type http taskmaster https://app.getgram.ai/mcp/your-taskmaster-slug -H "MCP-TASKMASTER-API-KEY: <your-api-key>"
```

This command:
- Creates an MCP server configuration named `taskmaster`
- Uses HTTP transport to connect directly to the Gram-hosted MCP server
- Passes the Taskmaster API key as a header

### Managed Authentication

If you're using the **Managed Authentication** configuration, replace `<your-gram-api-key>` with your actual Gram API key and `your-taskmaster-slug` with your MCP server slug:

```
/mcp add --type http taskmaster https://app.getgram.ai/mcp/your-taskmaster-slug -H "Gram-Environment: default" -H "Authorization: Bearer <your-gram-api-key>"
```

This command:
- Creates an MCP server configuration named `taskmaster`
- Uses HTTP transport to connect directly to the Gram-hosted MCP server
- Uses the default Gram environment (change `default` to your environment name if needed)
- Passes the Gram API key in the Authorization header

### Verifying the connection

Check that the server was added successfully by running:

```
/mcp list
```

You should see `taskmaster` in the list of configured servers.

To see the full configuration details:

```
/mcp get taskmaster
```

This will display the server type, URL, headers, and other configuration details.

## Managing MCP servers

Factory CLI provides several `/mcp` slash commands to manage your MCP server configurations from within a `droid` session:

### List all servers

```
/mcp list
```

Shows all configured MCP servers with their basic information.

### View server details

```
/mcp get taskmaster
```

Displays the full configuration for a specific server.

### Remove a server

```
/mcp remove taskmaster
```

Removes the server configuration from Factory CLI.

## Troubleshooting

### Server not found

If Factory CLI can't find your server:

```
# Check if the server is listed
/mcp list

# Remove and re-add the server
/mcp remove taskmaster
/mcp add --type http taskmaster https://app.getgram.ai/mcp/your-taskmaster-slug -H "MCP-TASKMASTER-API-KEY: <your-api-key>"
```

### Authentication errors

If you get authentication errors:

- Verify your Gram API key in the dashboard under **Settings > API Keys**.
- For Managed Authentication, check that the `Authorization` header is correctly formatted in the `/mcp add` command.
- For Pass-through Authentication, ensure your Taskmaster API key is correct.
- Verify that the Taskmaster API base URL is accessible.

### Configuration format issues

If you're having issues with environment variables or headers:

- For HTTP servers, use `-H "Key: Value"` format (note the colon and space).
- For stdio servers, use `-e KEY=VALUE` format.
- Ensure headers and environment variables are properly formatted without extra quotes.

### Tool calls not working

If Factory CLI isn't calling the tools:

- Test the MCP server in the **Gram Playground** first to ensure it's working correctly.
- Check that the toolset includes the tools you want to use.
- Verify the environment is correctly configured with the required variables in Gram.
- Use `/mcp get taskmaster` to verify the server configuration is correct.

### Tools not appearing

If the tools aren't available:

- Test the MCP server in the **Gram Playground** first to ensure it's working.
- Check that the toolset includes the tools you want to use.
- Verify the environment is correctly configured in Gram.
- Run `/mcp list` to confirm the server is loaded.
